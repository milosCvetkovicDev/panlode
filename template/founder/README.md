# Founder folder

**The rule:** your founder profile filters, ranks and can kill ideas. It never generates them. "I could
build this" is not a signal; ideas come from observed pain in `signals/`.

| File | Used for |
|---|---|
| `profile.md` | what you can build and deliver fast; feeds `score_fit` and `score_speed` |
| `constraints.md` | hard limits and vetoes; imported into `CLAUDE.md`, so every session sees it |
| `channels.md` | where you can actually reach prospects; feeds `score_reach` |

Fill in every `<placeholder>` before the first `/scout-online`. Keep money and identity data (tax IDs,
bank accounts, addresses) out of these files. A CV or other private file can sit here under a name that
`.gitignore` excludes (`founder/*.pdf`); never quote it into records.
